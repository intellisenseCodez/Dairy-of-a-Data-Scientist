Contribute to the diary

The glossary is open. Developers, data scientists and educators can add terms, fix definitions and improve examples through a pull request.

1. Fork the repo

Fork the project on GitHub and clone it. Run pip install -r requirements.txt then flask run to preview locally.

2. Add or edit a term

Open data/terms.json and add one object to the list, using the format below. The site updates on restart.

3. Open a pull request

Describe what you changed and why. A maintainer reviews it for accuracy and clarity before it goes live.

{
  "term": "Term name",
  "level": "Beginner",
  "definition": "One or two plain-language sentences.",
  "example": "A short, concrete example.",
  "related": ["Related term", "Another related term"]
}

Level must be Beginner, Intermediate or Advanced. The app checks this on startup and refuses to run if an entry is invalid.

  • Write for a beginner first, then add depth in the example.
  • Keep the definition under 40 words and use your own words.
  • Related terms must match the exact name of an existing entry.
  • Cite a source in your pull request when a claim is technical or contested.
